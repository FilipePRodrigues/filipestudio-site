## ✨ Destaques

- 🎨 Identidade visual **neon** (Violeta · Azul · Ciano · Laranja)
- 📱 100% responsivo, mobile-first
- ⚡ Build enxuto com **Vite + React + TypeScript**
- 🧭 Seções: hero, serviços, benefícios, processo, portfólio, planos, FAQ e contato
- 💬 Captação de leads via **WhatsApp** e **e-mail** com mensagem pré-preenchida
- 📝 **Blog** com publicação automatizada por GitHub Issues
- 🌙 Tema claro/escuro
- 🚀 Deploy automático no **GitHub Pages**
- 📊 **Google Analytics** + **Search Console** integrados

## 🚀 Rodando localmente

```bash
# 1. Clone
git clone https://github.com/FilipePRodrigues/filipestudio-site.git
cd filipestudio-site

# 2. Dependências
npm install

# 3. Dev server
npm run dev

# 4. Build de produção
npm run build
```

---

## 📦 Deploy

Cada `git push` na branch `main` dispara o workflow em  
[`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml)  
e publica automaticamente em:

🔗 **[filipeprodrigues.github.io/filipestudio-site](https://filipeprodrigues.github.io/filipestudio-site/)**

Para publicar um post, basta abrir uma Issue com label `blog`:

## 📁 Estrutura

```
├── docs/                  # banners e assets do README
├── public/                # logos, favicons, manifest, og-image
├── scripts/               # issue-to-post.mjs (automação do blog)
├── src/
│   ├── components/        # Hero, Services, Pricing, Contact, Blog...
│   ├── content/blog/      # posts em Markdown
│   ├── data/              # conteúdo do site (copy e planos)
│   ├── hooks/             # theme, scroll reveal
│   ├── lib/               # blog, markdown, seo, asset helpers
│   └── index.css          # design tokens da marca
└── .github/workflows      # deploy Pages + blog from issue
```
